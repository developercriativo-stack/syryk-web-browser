SYRYK WEB BROWSER 2.0 — PRIVACY POLICY / GITHUB PAGES

1. Abra index.html em um editor de texto.
2. Substitua:
   [SUBSTITUA_PELO_SEU_EMAIL_DE_SUPORTE]
   [SUBSTITUA_PELA_URL_DE_SUPORTE_SE_HOUVER]
   [REPLACE_WITH_YOUR_SUPPORT_EMAIL]
   [REPLACE_WITH_SUPPORT_URL_IF_AVAILABLE]

3. Crie no GitHub um repositório público, por exemplo:
   syryk-privacy

4. Envie index.html para a raiz do repositório.

5. No GitHub:
   Settings > Pages > Build and deployment
   Source: Deploy from a branch
   Branch: main
   Folder: /(root)

6. A URL normalmente ficará:
   https://SEU_USUARIO.github.io/syryk-privacy/

7. Abra essa URL em janela anônima para confirmar que:
   - carrega sem login;
   - usa HTTPS;
   - não retorna 404;
   - o nome "Syryk Web Browser 2.0" aparece;
   - os dados de contato já foram substituídos.

8. Use a URL final no campo "Privacy policy URL" do Partner Center.

IMPORTANTE
A política deve continuar alinhada ao comportamento real do app.
Se no futuro o Syryk passar a coletar telemetria remota, sincronizar contas,
usar analytics próprio, publicidade própria ou qualquer novo serviço de dados,
a política deve ser atualizada antes da publicação dessa versão.
